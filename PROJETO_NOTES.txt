==================================================
O QUE É O PROJETO
==================================================
API Rails (JSON only, ActionController::API) para a empresa "Quero
Educação" gerenciar mensalidades de alunos pagas a instituições de
ensino.

Entidades exigidas pelo desafio:
- Instituição de Ensino: nome (único, not null), CNPJ (só números,
  único), tipo (Universidade/Escola/Creche)
- Aluno: nome (único, not null), CPF (só números, único, not null),
  data de nascimento, telefone celular (inteiro), gênero (M ou F),
  meio de pagamento (Boleto ou Cartão)
- Matrícula: valor total do curso (decimal, >0), quantidade de
  faturas (inteiro, >=1), dia de vencimento das faturas (inteiro,
  1-31), nome do curso, ID instituição (FK), ID aluno (FK)
- Fatura: valor (decimal, not null), data de vencimento (not null),
  ID da matrícula (FK), status (Aberta/Atrasada/Paga, default
  Aberta)

Restrições extras do desafio:
- Soma das faturas de uma matrícula = valor total da matrícula
- Quantidade de faturas da matrícula = quantidade de faturas
  associadas de fato
- Regra de data de vencimento: se o "dia de vencimento" recebido for
  <= dia atual do mês, a 1a fatura cai no mês seguinte; senão, no mês
  atual. Cada fatura subsequente soma 1 mês à anterior.
  Exemplo: hoje 15/08/2018, dia_vencimento=10, valor=2000, qtd=5 ->
  faturas de R$400 vencendo em 10/09, 10/10, 10/11, 10/12, 10/01/2019.

Ações mínimas exigidas pela API:
- Listar e criar Instituição de Ensino
- Listar e criar Aluno
- Listar e criar Matrícula (cria as Faturas automaticamente)
- Listar Faturas

==================================================
COMANDOS ÚTEIS USADOS NESTE PROJETO
==================================================
- Rodar servidor:            bin/rails s  (porta 3000)
- Ver processo numa porta:   ss -ltnp | grep :3000
- Matar processo:             kill <PID>
- Rodar migrations pendentes: bin/rails db:migrate
- Ver status das migrations:  bin/rails db:migrate:status
- Refazer 1 migration específica (rollback + up):
                               bin/rails db:migrate:redo VERSION=<id>
- Console Rails (criar dados na mão): bin/rails c
- Ver log de erro:            tail -n 60 log/development.log
